# Enterprise

Vysor Enterprise licenses teams and organizations, adding organization-wide controls on top of [Vysor Pro](/pro).

## What's Included

- Every seat includes the [Vysor Pro](/pro) feature set.
- **Share access management via web:** control who can connect to your team's shared device servers ([Vysor Share](/share#access-control)) — managed with your organization's user directory instead of per-server whitelists.
- **Flexible organizational licensing:** seats are managed per-organization.
- Server access can use the **Vysor Enterprise** whitelist mode: users belonging to your organization are allowed automatically; membership is managed with your organization's account tools.

Enterprise subscriptions are managed at [billing.vysor.io](https://billing.vysor.io).

## Use Cases

- **Team device farms.** Run **Share All Devices** on bench machines; the team connects to any device from anywhere, with per-device usage visibility (who is using what) and access restricted to organization members.
- **Remote ADB.** Developers share devices with teammates or contractors over Vysor Share for full remote debugging — install builds, inspect logcat, run Android Studio — without shipping hardware.
- **QA access from distributed teams.** Testers connect to the same physical devices from distributed locations, keeping everyone on identical hardware and builds.
